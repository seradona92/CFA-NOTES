R28 — 손익계산서 · EPS
  • 수익 인식은 현금 수취가 아니라 수행의무 이행 시점
  • Agent는 순액(수수료)만 매출 — 총액 인식하면 매출 과대계상
  • 계약 변경은 전진 적용 — 전년도 IS 수정 안 함
  • Unusual/Infrequent는 계속영업 안(세전), Discontinued는 아래(세후)
  • 감가상각 방법 변경 = 추정 변경 = Prospective ★★
  • LIFO→FIFO는 정책 변경 = Retrospective, 반대(FIFO→LIFO)는 전진법
  • 오류 수정은 Retrospective Restatement + 주석 공시
  • Basic EPS 분모는 기말 주식수가 아니라 가중평균(WASO)
  • 주식배당·액면분할은 기초까지 소급, 월수 가중 안 함 ★★
  • TSM은 평균시장가 — 기말주가 쓰면 오답 ★★
  • 행사가 > 평균시장가면 Antidilutive → 제외
  • CB만 분자에 이자 ×(1−t), 전환우선주 배당은 세조정 없음 ★★
  • 옵션·워런트는 분자 변화 없음, 분모만 순증
  • 희석증권은 각각 따로 판정 — 묶어서 판단 금지
  • Diluted EPS > Basic EPS는 불가능 — 나왔다면 Antidilutive를 넣은 것
  • Common-size IS 기준 = Revenue
  • 감가상각 방법이 달라도 총 비용은 동일 — 시점 배분만 다름
R29 — 재무상태표
  • FVOCI 평가손익은 OCI → AOCI, FVPL은 NI ★★
  • 상각후원가(HTM)는 평가손익 아예 인식 안 함
  • 이자·배당수익과 손상차손은 세 분류 모두 NI — 차이는 미실현 평가손익뿐
  • 유동 정의 = 1년과 영업순환주기 중 더 긴 것
  • 상환우선주는 형식이 자본이어도 금융부채
  • 내부창출 영업권은 인식 불가
  • 영업권은 상각 X, 매년 손상검사 O, 환입 X
  • IFRS는 개발비, GAAP은 소프트웨어가 자본화 예외 — 서로 다른 항목 ★
  • 자기주식 매입 → EPS↑·자본↓ / 소각 → EPS·자본 불변 ★
  • Common-size BS 기준 = Total Assets ★
  • DTL은 IFRS·GAAP 모두 비유동
  • 장부가 ≠ 시장가치 — 측정기준이 혼재하고 인적자본·브랜드는 미인식
R30–31 — 현금흐름표
  • GAAP: 배당 지급만 CFF, 이자 지급은 CFO ★★
  • 배당 수취(CFO)와 배당 지급(CFF)을 바꿔놓는 문제 빈출
  • 간접법에서 처분이익은 차감, 처분손실은 가산 ★★
  • 감가상각비 증가는 CFI가 아니라 CFO 조정 항목
  • 직접법·간접법은 CFO만 방식이 다르고 금액은 동일, CFI·CFF는 완전 동일
  • 비현금거래는 CF에 표시 안 하지만 주석 공시 대상
  • 자산 증가 → CFO 차감 / 부채 증가 → CFO 가산
  • DTL 증가는 CFO 가산 (실제 안 낸 세금)
  • FCFF는 세후 이자 가산, FCFE는 가산 안 함 ★
  • FCFE = CFO − FCInv + Net Borrowing
  • 배당 선언액 ≠ 지급액 — 미지급배당 증감 반영
  • 감가상각누계액 증가 = IS 감가비면 PP&E 처분 없음
  • CFO 증가가 운전자본 압축 때문이면 지속 불가능 — CF 품질 낮음
  • Common-size CF 기준 = Revenue
  • 단기매매(FVPL) 증권 매매는 CFO, 투자목적은 CFI
R32–33 — 재고 · 장기자산
  • 인플레이션기 FIFO: 재고↑·COGS↓·NI↑·세금↑·CFO↓
  • LIFO Reserve를 재고에 더해 FIFO로 환산 — 세금 고려 시 현금·RE도 조정
  • LIFO Liquidation은 LIFO Reserve와 다른 개념 — 판매량>구매량 → COGS↓ → NI↑ (지속 불가)
  • Perpetual vs Periodic: FIFO는 동일, LIFO는 다름
  • IFRS 손상 회수가능액 = max(FV−처분부대원가, VIU) — NRV는 재고 용어 ★★
  • GAAP 손상은 2단계: 1단계는 할인 안 한 미래CF와 비교
  • GAAP 손상 환입은 held for use만 불허 — held for sale은 허용 ★★
  • 감가상각 방법은 IFRS·GAAP 모두 정액·정률·생산량비례 허용 ★
  • DDB는 계산식에서 잔존가치를 빼지 않지만 잔존가치 아래로는 상각 못 함
  • Component Depreciation: IFRS 필수, GAAP 허용하나 잘 안 씀
  • Revaluation Gain은 OCI, Loss는 NI — 단 기존 OCI 잔액 있으면 먼저 상계
  • Investment Property FV Model은 Gain도 NI — PPE Revaluation과 반대 ★
  • 이자 자본화분은 CFO가 아니라 CFI로 나감
  • 재고 평가감은 회전율에 양방향 영향 가능
  • Discontinued Operation은 정책 변경이 아니라 표시·분류 문제 ★
R34 — 리스 · 연금 · 주식보상
  • Finance Lease 기준에 75%·90% 숫자 없음 — "most of useful life", "PV ≥ fair value" ★★
  • 5가지 중 하나라도 해당하면 Finance Lease
  • ROU asset은 무형자산으로 분류 (PP&E 아님) — 슈웨이저 명시
  • GAAP Operating Lease도 BS에 ROU·부채 인식 — 상각·IS·CF만 다름
  • Finance는 초기 IS비용이 더 크고, 총 비용은 양쪽 동일
  • Finance가 Operating보다 CFO 높고 CFF 낮다
  • Operating은 ROU = Lease Liability가 매 기간 일치, Finance는 중간에 ROU < Liab
  • Lessor는 Finance·Operating 모두 전액 CFO — Lessee Finance(원금 CFF)와 다름 ★
  • 저가치(≤$5,000) 면제는 IFRS만, 단기(≤12개월)는 양쪽
  • IFRS Net Interest = Funded Status 순액 × 할인율 — PBO에만 곱하면 오답 ★★
  • DB형 할인율 인상 → PBO↓ → Funded Status 개선되어 보임
  • DC형은 Pension Expense = 기여액, BS 잔액 없음
  • Benefit 지급은 PBO·Plan Asset 동시 감소 → Funded Status 불변
  • SBC 비용은 grant date 주가가 아니라 옵션 FV(BSM/Binomial) ★★
  • Grant date 이후 주가 변동은 비용에 무관 (FV 고정)
  • SBC 비용 인식해도 Equity 총액 불변 (RE↓ = APIC↑)
  • 옵션 변동성 가정↓ → 보상비용↓ → NI↑ (이익조정 통로)
  • 리스 만기분석에서 차기 원금 = 유동부채 → 유동비율에 직접 영향
  • 변동리스료: 지수·이율 연동은 부채 포함, 매출·사용량 연동은 제외 후 발생시 비용
R35 — 법인세
  • 자산과 부채가 정반대: 자산 CV>Tax Base → DTL / 부채 CV>Tax Base → DTA ★★
  • 자산 Tax Base > CV → DTA
  • 영구적 차이는 DTA·DTL을 만들지 않고 유효세율만 바꾼다 ★
  • 일시적 차이는 유효세율을 바꾸지 않는다
  • Income Tax Expense = Taxes Payable + ΔDTL − ΔDTA — 납부액과 다름
  • Current Tax는 당기 세율, Deferred는 미래 제정세율 ★
  • 세율 인상 → DTA·DTL 둘 다 증가 (반대 방향 아님) ★★
  • 평가충당금 증가 → 순DTA↓ → 세금비용↑ → NI↓, 미래이익 전망 악화 신호 ★★
  • 평가충당금 계정은 U.S. GAAP만 — IFRS는 인식 단계에서 제한
  • DTL이 반전 안 될 것으로 보면 분석상 자본으로 재분류
  • "Pretax × 세율"은 영구차이·세율변동 없을 때만 성립
  • 감가상각(세무 가속) → DTL / 선수임대료·대손·보증·퇴직급여 → DTA
R27 · 36 · 38 — 개요 · 품질 · 모델링
  • MD&A·Proxy는 감사 대상 아님 — 본문 + 주석만 ★★
  • 적정의견 = 회계처리 문제 없음 ≠ 재무상태 우수
  • 합리적 확신이지 절대적 확신 아님 — 부정 전수 적발 보장 아님
  • 재무제표 작성 책임은 경영진, 내부통제 책임도 경영진
  • Adverse: 증거 충분 + 왜곡 심각 / Disclaimer: 증거 자체 부족 ★★
  • 계속기업 의문은 강조사항으로 적정의견에도 붙을 수 있음
  • Segment 보고 기준 = 매출·자산·이익 중 하나라도 10% 이상
  • 보고품질 높고 이익품질 낮은 건 가능 — 역은 불가능 ★
  • 가공거래 단계에서는 이익품질을 평가할 수조차 없다
  • 자본화·긴 내용연수·정액법·손상 지연 = 공격적 / 반대는 보수적
  • 보수적 회계도 지나치면 왜곡(Big Bath) — 목표는 중립
  • Channel stuffing → 매출채권 회전일수 급증 / Bill-and-hold → 재고가 안 줄어듦
  • non-GAAP 지표 사용 시 GAAP과의 조정표 공시 의무
  • Porter 5 forces가 약할수록 가격결정력이 높다
  • Conservatism = Anchoring(기존 예측 고착) ↔ Representativeness(분류 의존 → base-rate neglect) ★
  • 신뢰구간이 지나치게 좁다 → Overconfidence / 모델 과잉복잡화 → Illusion of control
  • 경기순환 기업의 예측기간은 충분히 길게 — 한 국면만 담으면 왜곡
