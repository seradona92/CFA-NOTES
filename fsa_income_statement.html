현금 시점 vs 수익 시점 — 계정 결정
현금 먼저 → Unearned Revenue (부채)
  • 돈 받았지만 아직 이행 X
  • ex) 조선업 선수금, 구독료 선납
  • 유동성 good, 하지만 부채
이행 먼저 → Accounts Receivable (자산)
  • 이행했지만 아직 돈 못 받음
  • ex) 외상 매출
  • 수익 인식 O, 현금 X
인식 시점 — Over Time vs Point in Time
구분조건예시
Over time (기간에 걸쳐)고객이 진행 중 통제 / 자산에 대체 용도 없고 대금청구권 있음장기 건설, 조선업 → 진행률만큼 매년 인식
Point in time (한 시점)위 조건 미충족일반 제품 판매 → 인도 시점 일괄
10억 건물 10년 시공 → over time이면 연 1억씩. point in time이면 완공 전까지 매출 0.
특수 상황 — 시험 단골
Principal vs Agent
  • Principal(주체): 재화 통제 → 총액(gross) 매출
  • Agent(대리인): 중개만 → 순액(net) = 수수료만 매출
  • Agent가 총액 인식하면 매출 과대계상
계약 변경 (Contract revision)
  • 전년도 IS 수정 안 함
  • 변경 시점부터 prospective 반영
  • 공사금액 변동 → 당해부터 새 금액
공시 (Disclosure)
  • 수익을 분해(disaggregation)한 정보 — 제품별·지역별·계약유형별
  • 계약 잔액(수취채권, 계약자산, 계약부채)과 변동
  • 남은 수행의무 및 인식 예상 시기
  • 수익인식에 사용한 판단과 추정
Matching Principle
비용은 관련 수익을 인식하는 기간에 대응시켜 인식 — 현금 지출 시점 아님
유형처리예시
수익과 직접 대응수익 인식 시 동시 비용COGS
기간 배분내용연수에 걸쳐 배분감가상각, 무형자산 상각
즉시 비용발생 즉시 IS판관비, 광고비, 대부분 R&D(GAAP)
추정이 개입되는 비용 ★ (Reporting Quality 연결)
Bad Debt Expense (대손상각비)
  • 매출채권 회수불능 추정 → Allowance 설정
  • 회계는 보수적으로 미리 손실 인식
  • 세무는 확정돼야 인정 → DTA 발생
  • 추정 축소 = 이익 부풀리기 수단
Warranty Expense (품질보증)
  • 판매 시점에 미래 보수비용 추정 인식
  • 실제 지출은 나중 → DTA 발생
  • 추정치 조작 가능 영역
⚠ 추정 비용(대손·보증·감가상각 가정)은 모두 경영진 재량 → Earnings Management의 주 통로
감가상각 방법이 IS에 미치는 영향
방법초기 비용초기 NI비고
Straight-Line (정액)낮음높음(원가−잔존) ÷ 내용연수
Accelerated / DDB (정률)높음낮음BV × 2/내용연수 (잔존가치 차감 안 함)
Units-of-Production생산량 비례(원가−잔존) × 생산비율
  • 내용연수↑ 또는 잔존가치↑ → 감가비↓ → NI↑ (공격적 회계)
  • 총 비용은 방법과 무관하게 동일 — 시점 배분만 다름
IS 구조 — 비경상항목의 위치 ★
Revenue − COGS = Gross Profit − Operating Expense (SG&A, 감가상각) = Operating Profit (EBIT) − Interest Expense = Pretax Income (EBT) ← Unusual/Infrequent 여기까지 포함 (세전) − Tax Expense = Income from Continuing Operations (계속영업손익, 세후) ± Discontinued Operations (net of tax) ← 세후로 별도 표시 = Net Income
⭐ 시험 포인트: Unusual/Infrequent는 계속영업 안(세전), Discontinued는 계속영업 아래(세후)
두 가지 비경상항목
Unusual or Infrequent Items
  • 비경상적이거나 드문 항목 (둘 중 하나)
  • 계속영업손익에 포함, 세전 표시
  • ex) PPE 처분손익, 구조조정비, 자산상각
  • 분석 시 지속성 판단 → 정상화(normalize)
Discontinued Operations
  • 물리적·영업적으로 분리 가능한 사업의 중단
  • 세후(net of tax)로 계속영업 아래 별도
  • 과거 IS도 재작성해 비교 가능하게
  • 미래 예측에서 제외해야 할 항목

Simple Capital Structure
  • 희석증권 없음
  • Basic EPS만 공시
Complex Capital Structure
  • CB, CPS, 옵션, 워런트 보유
  • Basic + Diluted 둘 다 공시
  • 희석 경고 신호 제공 목적
Basic EPS ★
Basic EPS = (Net Income − Preferred Dividends) ÷ Weighted Average Shares Outstanding
  • 분자: 보통주 귀속 이익 → 우선주 배당 차감
  • 분모: 기말 주식수 아님 → 가중평균(WASO) (분자가 flow이므로 분모도 flow)
  • 자기주식(Treasury Stock)은 제외 — 유통주식만
가중평균 주식수(WASO) 계산 규칙
사건처리가중
신주 발행 (증자)주식수 ↑발행일부터 월수 비례
자기주식 매입주식수 ↓매입일부터 월수 비례
자기주식 재발행주식수 ↑재발행일부터 월수 비례
Stock Dividend / Split주식수 ↑기초까지 소급 (시간가중 X)
⚠ 주식배당·액면분할은 자원 유입이 없는 단순 분할 → 기초(또는 그 이전 발행분의 발행시점)까지 소급 적용. 월수 가중하지 않는다.
예제 — WASO 계산
조건
  • 1/1 기초 10,000주
  • 4/1 4,000주 신주 발행
  • 7/1 10% 주식배당
  • 9/1 자기주식 3,000주 매입
1/1 기초분: 10,000 × 1.10 × 12/12 = 11,000 4/1 발행분: 4,000 × 1.10 × 9/12 = 3,300 9/1 자사주: (3,000) × 4/12 = (1,000) WASO = 13,300주
7/1 주식배당 10%는 그 이전에 존재하던 모든 주식(기초분 + 4/1 발행분)에 소급 적용 → ×1.10. 9/1 자사주는 주식배당 이후라 조정 없음.
Diluted EPS — 전체 공식
(NI − Pref Div) + 전환우선주 배당 + 전환사채 이자×(1−t) Diluted EPS = ───────────────────────────────────────────────────────── WASO + 전환우선주 주식 + 전환사채 주식 + 옵션 순증주식
⭐ "If-converted" — 기초(또는 발행일)에 전환된 것으로 가정. 실제 전환 가능 여부와 무관.
증권별 조정 — 분자/분모 ★★
증권분자 조정분모 조정방법
전환우선주 (CPS)+ 우선주 배당
(세효과 없음)		+ 전환 시 주식수If-converted
전환사채 (CB)+ 이자 × (1 − 세율)
(세후 이자만)		+ 전환 시 주식수If-converted

⚠ CB만 세효과 반영 — 이자는 손금이라 전환 시 절세효과도 사라지기 때문. 우선주 배당은 원래 손금이 아니므로 세조정 없음.
Treasury Stock Method (옵션·워런트) ★
순증 주식수 = 행사주식수 − (행사주식수 × 행사가 ÷ 평균시장가) = 행사주식수 × (평균시장가 − 행사가) ÷ 평균시장가
  • 행사로 들어온 현금으로 평균시장가에 자사주를 되산다고 가정
  • 기말주가 아님 — 반드시 평균시장가(AMP) 사용
  • 행사가 < 평균시장가 → 희석 (ITM)
  • 행사가 > 평균시장가 → 행사 안 함 → Antidilutive, 제외
예제
옵션 100,000주 · 행사가 $15 · 평균시장가 $20 현금유입 = 100,000 × 15 = $1,500,000 재매입 = 1,500,000 ÷ 20 = 75,000주 순증 = 100,000 − 75,000 = 25,000주
풀이 절차 — 지문 신호 → 공식 선택
Treasury Stock Method (옵션·워런트)
신호: options / warrants · exercise price · average market price
  • ① 행사 시 발행되는 주식수 확인 (n)
  • ② 유입 현금 = n × 행사가
  • ③ 재매입 주식 = 유입현금 ÷ 평균시장가
  • ④ 순증 = n − 재매입 → 분모에만 가산
  • 행사가 > 평균시장가면 여기서 중단 (Antidilutive)
If-Converted (CB · 전환우선주)
신호: convertible · conversion ratio · 좌당 n주
  • ① 전환 시 증가 주식수 계산
  • ② 분자 조정: CB는 이자×(1−t), 우선주는 배당 그대로
  • ③ 주당 효과 = 분자조정 ÷ 증가주식수
  • ④ Basic EPS와 비교 → 작으면 희석, 크면 제외
  • 증권이 여러 개면 각각 ③④ 반복
희석 여부 판정 — 빠른 방법 ★
증권주당 효과 계산판정
전환우선주우선주 배당 ÷ 전환 주식수Basic EPS보다 작으면 희석
크면 Antidilutive → 제외
전환사채이자×(1−t) ÷ 전환 주식수
  • 희석증권이 여러 개면 각각 따로 판정 — 묶어서 판단 X
  • 기중 발행된 희석증권은 보유기간만큼만 가중
  • Antidilutive를 포함시키면 오답 — Diluted EPS는 절대 Basic EPS보다 클 수 없다
예제 — 전환사채
보통주 귀속이익 $2,500,000 · 주식 1,000,000주 → Basic EPS = $2.50 CB: 2,000좌 × $1,000 par, 5%, 좌당 120주 전환, 세율 30% 전환 주식수 = 2,000 × 120 = 240,000주 세후 이자 = 2,000,000 × 5% × (1 − 0.30) = $70,000 주당 효과 = 70,000 ÷ 240,000 = $0.29 < $2.50 → 희석 O Diluted EPS = (2,500,000 + 70,000) ÷ (1,000,000 + 240,000) = 2,570,000 ÷ 1,240,000 = $2.07
Common-Size Income Statement
기준(100%) = Revenue (Top-line) — BS는 Total Asset 기준이니 혼동 주의
  • 모든 항목을 매출 대비 %로 표시 → 규모가 다른 기업 간 비교 가능
  • 시계열로 보면 원가구조 변화가 드러남
Income Statement 비율
비율공식의미

Comprehensive Income (포괄이익)
Comprehensive Income = Net Income + Other Comprehensive Income (OCI)
OCI 4+1 항목 (암기) ★
  • 0. 재평가잉여금 (Revaluation surplus) — IFRS만
  • 1. 해외사업장 외화환산손익
  • 2. 확정급여제도 재측정손익 (연금)
  • 3. 현금흐름위험회피 파생상품 평가손익
  • 4. FVOCI 금융자산 평가손익 (구 매도가능증권)

시험 함정 Top Picks
⚠ 자주 틀리는 것
  • 감가상각 방법 변경 = 추정 변경 = Prospective (정책 변경 아님)
  • TSM에 기말주가 쓰면 오답 — 평균시장가
  • 전환우선주 배당은 세효과 없음 (CB 이자만 ×(1−t))
  • 주식배당·분할은 월수 가중하지 않고 소급
  • Diluted EPS > Basic EPS는 불가능 — Antidilutive 포함했다는 뜻
  • Discontinued는 세후, Unusual은 세전
Reading 28 — Quiz
Q1수익 인식 시점으로 가장 적절한 것은?
정답: B
수익은 Satisfaction of Performance Obligation 시점에 인식. 현금 수취는 무관 — 먼저 받으면 Unearned Revenue(부채), 나중에 받으면 Receivable(자산).
Q2감가상각 방법을 정액법에서 정률법으로 변경했다. 회계처리는?
정답: B
감가상각 방법 변경은 회계정책이 아니라 회계추정 변경 → Prospective. LIFO→FIFO 같은 정책 변경만 Retrospective.
Q3중단사업손익(Discontinued Operations)의 표시 방법은?
정답: B
Discontinued = net of tax로 계속영업 아래 별도 표시. Unusual/Infrequent는 계속영업 안에 세전 표시.
Q4기초 100,000주, 5/1에 30,000주 발행, 7/1에 10% 주식배당. Basic EPS의 WASO는?
정답: B
100,000×1.10×12/12 = 110,000
30,000×1.10×8/12 = 22,000

Q5보통주 300,000주, 워런트 100,000개(행사가 $50), 평균주가 $55, 기말주가 $60. Diluted EPS의 주식수는?
정답: B

300,000 + 9,091 = 309,091주

C3[계산] 보통주귀속이익 $1,800,000, 주식 600,000주. CB 1,000좌(액면 $1,000, 6%, 좌당 40주), 세율 25%. 희석 여부와 Diluted EPS는?
