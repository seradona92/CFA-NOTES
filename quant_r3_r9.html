판단 규칙 — 결론 내리는 법
Reject H₀ 조건
  • p ≤ α → reject H₀
  • 검정통계량이 rejection region에 위치 → reject
    양측: |test stat| > critical / 좌측 단측: test stat < −critical
  • μ₀가 CI 밖 → reject
Fail to Reject H₀ 조건
  • p > α → fail to reject
  • 검정통계량이 rejection region 밖 → fail
    양측: |test stat| ≤ critical
  • μ₀가 CI 안 → fail to reject

MWR vs TWR ★★ — R1 최다 출제
Money-Weighted (MWR)
  • = 포트폴리오 현금흐름의 IRR
  • 입출금 시점·규모의 영향을 받는다
  • 투자자가 현금흐름을 통제할 때 적합
  • 계산기 CF → IRR 기능
Time-Weighted (TWR)
  • 기간별 HPR을 기하 연결: [(1+R₁)(1+R₂)…]^(1/n) − 1
  • 입출금 영향 제거 → 매니저 평가의 표준
  • 현금흐름 발생 시점마다 구간을 쪼개서 계산
⚠ 유리한 시점에 큰 돈이 들어오면 MWR > TWR, 불리한 시점이면 반대. "펀드매니저 성과 평가" 키워드 → TWR.

산포 (Dispersion)
핵심 산포 측도
  • Range = max − min
  • MAD = Σ|Xᵢ − X̄| / n
  • s² = Σ(Xᵢ − X̄)² / (n−1) ← Bessel's correction
  • CV = s / X̄ ← 단위당 리스크 "risk per unit of expected return"
  • Target semideviation → downside risk만 측정 "below target"
S_target = √[ Σ(Xᵢ−B)² / (n−1) ] for Xᵢ ≤ B
Outlier 처리
  • Trimmed mean (절사평균) → 양 극단 일정 % 제거 (discard)
  • Winsorized mean → 극단값 대체 (substitute)
Trimmed = 버림 / Winsorized = 바꿈
Skewness & Kurtosis ★
Skewness (비대칭도)
  • Positive skew: Mode < Median < Mean (오른쪽 꼬리)
  • Negative skew: Mean < Median < Mode (왼쪽 꼬리) → 리스크 관리 중요
  • Symmetric: Mean = Median = Mode
Kurtosis (첨도)
  • Leptokurtic: excess kurtosis > 0 → fat tails ★
  • Platykurtic: excess kurtosis < 0 → thin tails
  • Excess kurtosis = kurtosis − 3 (정규분포 기준)
  • 실제 자산수익률 = leptokurtic → tail risk 과소평가 위험
R3 문제 키워드 매핑
not affected by extreme values / outliers→median 사용

downside risk only / below target→Target semideviation
long upper (right) tail→positively skewed → Mean > Median > Mode
long lower (left) tail→negatively skewed → Mean < Median < Mode
fat-tailed / more peaked than normal→leptokurtic → excess kurtosis > 0
compounded / multi-period return→geometric mean
excludes extreme / replaces extreme→trimmed mean / winsorized mean

핵심 확률 공식
기본 공식
P(A∪B) = P(A) + P(B) − P(A∩B) ← OR
P(A∩B) = P(A) × P(B|A) ← AND
P(A|B) = P(A∩B) / P(B) ← Conditional
독립: P(A∩B) = P(A)×P(B) ← P(B|A) = P(B)
Bayes' Formula ★★
P(A|B) = [ P(B|A) × P(A) ] / P(B)
P(B) = P(B|A)×P(A) + P(B|Aᶜ)×P(Aᶜ)
  • 분자 = 내가 원하는 경우
  • 분모 = 해당 사건이 일어나는 모든 경우
  • "결과 → 원인 역방향" 문제에서 사용
기댓값 & 분산
E(X) = Σ [ P(xᵢ) × xᵢ ] ← 시나리오별 확률 가중합
Var(X) = Σ [ P(xᵢ) × (xᵢ − E(X))² ]
R4 문제 키워드 매핑
given that / conditional on→conditional probability P(A|B)
both A and B occur→P(A∩B) → AND
either A or B (or both)→P(A∪B) → OR → 더하고 교집합 빼기
cause / given outcome / given result→Bayes (결과 → 원인 역방향)
independent events→P(A∩B) = P(A)×P(B) 확인
based on past data / historical frequency→empirical probability
포트폴리오 수익률 & 분산
E(Rp) = wA×E(RA) + wB×E(RB)
σ²p = wA²σA² + wB²σB² + 2wAwB·Cov(A,B)
Cov(A,B) = ρ × σA × σB
순서: Cov 먼저 구하고 → σ²p 계산
Correlation 효과
ρ 값효과분산
ρ = +1분산효과 없음σp = wAσA + wBσB (최대)
ρ = 0공분산 = 0분산만 더함
ρ = −1완전 상쇄 가능분산 최소화 (완전 헤지)
ρ ↓ → 분산투자 효과 ↑ / "diversification benefit" → ρ < 1 → σp < 가중평균σ
Roy's Safety-First Criterion (SFR) ★★
목표: shortfall risk 최소화 → SFR 가장 큰 포트폴리오 선택
SFR = [ E(Rp) − RL ] / σp ← RL = threshold return (목표수익률)
  • SFR = Z-score와 동일 구조
  • SFR 클수록 표준정규분포에서 shortfall 확률(왼쪽 면적) 작아짐
  • "minimize the probability of falling below threshold" → SFR 최대화 선택
R5 문제 키워드 매핑
minimize the probability of falling below threshold→Roy's SFR → SFR 최대화
shortfall risk / threshold return / target return→SFR 문제 → RL에 숫자 대입
correlation = −1 → variance reduced to zero→완전 헤지 가능 (ρ=−1)
diversification benefit→ρ < 1 → σp < 가중평균σ

CLT & Standard Error
Central Limit Theorem (CLT) ★
  • n ≥ 30이면 모집단 분포 무관하게 표본평균 → 정규분포
  • E(X̄) = μ
  • Var(X̄) = σ²/n → SE = σ/√n
⚠ CLT는 z 사용 조건이 아님 — σ unknown이면 n이 커도 t 사용
Standard Error
σ 알 때: SE = σ/√n
σ 모를 때 (보통): s_x̄ = s/√n
  • n ↑ → SE ↓ → 추정 더 정확
Confidence Interval ★★
CI = X̄ ± z*(σ/√n) or X̄ ± t*(s/√n)
임계값 (Two-tailed 기준)
90% CI: z = 1.645
95% CI: z = 1.96
99% CI: z = 2.576
t vs z 선택
  • t 사용 (기본 ★): σ unknown → 거의 항상, df = n−1
  • z 사용: σ known (드문 경우)
  • n≥30은 z 조건이 아님
confidence ↑ → wider / n ↑ → narrower

회귀모델 기본
모델 구조
Yᵢ = b₀ + b₁Xᵢ + εᵢ
  • b₁ (slope) → X 1단위 증가 시 Y의 변화량
  • b₀ (intercept) → X = 0일 때 Y값
  • ε (error term) → 모델이 설명 못하는 부분
  • b̂₁ = Cov(X,Y) / Var(X)
  • b̂₀ = Ȳ − b̂₁X̄
OLS & Variation 분해
SST = SSR + SSE
  • SST = Σ(Yᵢ − Ȳ)² ← total variation
  • SSR = Σ(Ŷᵢ − Ȳ)² ← explained (모델이 설명)
  • SSE = Σ(Yᵢ − Ŷᵢ)² ← unexplained (잔차)
  • R² = SSR / SST
R² & 상관계수 관계 보완
Simple regression: R² = r² (상관계수의 제곱)
r = ±√R² ← 부호는 반드시 b₁(slope)과 일치
  • R²에서 역으로 r을 구할 때 단순히 √R²만 하면 틀릴 수 있음
  • b₁ > 0 이면 → r = +√R²
  • b₁ < 0 이면 → r = −√R² (부호 반드시 체크)
⚠ 계산문제에서 R² 주고 r 구하라 하면 → slope 부호 확인 먼저

t = r√(n−2) / √(1−r²) df = n−2
  • H₀: ρ = 0 (상관관계 없음)
  • Simple regression t-test(b₁)와 동일 구조
  • t² = F
Spearman Rank Correlation
rₛ = 1 − 6Σdᵢ² / n(n²−1) ← dᵢ = 순위 차이
t = rₛ√(n−2) / √(1−rₛ²) df = n−2
Chi-square Test of Independence (범주형) ★
두 범주형 변수가 독립인지 검정
χ² = ΣΣ (Oᵢⱼ − Eᵢⱼ)² / Eᵢⱼ
Eᵢⱼ = (행합 × 열합) / 전체
df = (r−1)(c−1) ← r=행수, c=열수
  • H₀: 두 변수는 독립
  • H₁: 두 변수는 연관있음
  • χ² 크면 → reject H₀ → 연관 있음

계산 함정 포인트
공식 함정
  • n≥30 이어도 σ unknown이면 → t-test (z 아님)
  • r = ±√R² → b₁ 부호 확인 필수
  • Geometric mean → 복리 수익률 (arithmetic mean 아님)
  • Spearman df → n−2 (Pearson과 동일)
  • Chi-square df → (r−1)(c−1) (n−1 아님)
해석 함정
  • Heteroskedasticity/Serial Correlation → SE 과소계상 → t 과대계상
  • Correlation = 0 → 선형관계 없음 (비선형은 가능)
  • Power ↑ = 좋은 것 (Type II Error ↓)
  • α ↓ → Type I ↓ BUT Type II ↑ (trade-off)
  • CLT는 z 사용 조건이 아님
Quant는 계산 문제가 아니라 "단어 → 개념 매칭 게임"이다
