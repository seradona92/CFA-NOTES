수익성 비율 전체
비율공식의미높으면여신 포인트
Gross Profit Margin
매출총이익률		 (Revenue − COGS) / Revenue 원가 제어 효율성 좋음 원가 관리 우수 COGS 상승 시 → 하락 추이 주목
Operating Profit Margin
영업이익률 (EBIT Margin)		 EBIT / Revenue 이자·세금 전 핵심 영업 효율 좋음 영업 효율 우수 금융비용 영향 없는 순수 영업력
Net Profit Margin
순이익률		 Net Income / Revenue 이자·세금까지 제외 최종 수익 좋음 전반적 수익성 DuPont 1번째 factor
EBITDA Margin EBITDA / Revenue 감가상각 제외 현금창출력 좋음 현금창출 우수 DSCR 계산의 분자로 활용
ROA
총자산이익률		 NI / Avg Total Assets
or EBIT(1−t) / Avg Assets		 자산 활용 수익성 좋음 자산 효율 = NPM × Asset Turnover
ROE
자기자본이익률		 NI / Avg Total Equity 주주 관점 수익성 좋음 but 원인 분석 필요 Leverage로 뻥튀기 가능 → DuPont 확인
ROCE
투하자본이익률		 EBIT / (Equity + LT Debt) 장기 투하자본 대비 수익 좋음 투자 효율 장기 자금조달 효율성 평가
⚠ ROE가 높아도 Leverage(부채) 때문이면 질 나쁜 ROE — 반드시 DuPont으로 원인 분해
활동성(회전율) 비율 전체
비율공식의미Days 버전방향
Inventory Turnover
재고자산회전율		 COGS / Avg Inventory 재고 소진 속도 DIO = 365 / Inv T/O 높을수록 좋음
AR Turnover
매출채권회전율		 Revenue / Avg AR
원칙: Credit Sales / Avg AR
(현금매출 제외, 신용매출만)		 매출채권 회수 속도 DSO = 365 / AR T/O 높을수록 좋음
AP Turnover
매입채무회전율		 COGS / Avg AP 매입채무 지급 속도 DPO = 365 / AP T/O 낮을수록 유리 (늦게 지급)
Fixed Asset Turnover
고정자산회전율		 Revenue / Avg Net Fixed Assets 고정자산 활용도 — 높을수록 좋음
Total Asset Turnover
총자산회전율		 Revenue / Avg Total Assets 전체 자산 활용도 — 높을수록 좋음 DuPont 핵심
Working Capital Turnover Revenue / Avg Working Capital 운전자본 효율성 — 높을수록 좋음
⚠ Inventory Turnover 분자는 반드시 COGS — Revenue 아님! 시험 함정
Cash Conversion Cycle (CCC) ★★
CCC = DIO + DSO − DPO
CCC = (365/Inv T/O) + (365/AR T/O) − (365/AP T/O)
CCC ↓ (좋음)
  • 현금 빨리 회수
  • 유동성 좋음
  • 운전자금 부담 낮음
CCC ↑ (나쁨)
  • 현금 묶임
  • 운전자금 부족 위험
  • 단기 유동성 악화
최소화 전략: DIO↓ + DSO↓ + DPO↑
유동성 비율 전체
⚠ 아래 실무 참고치는 여신심사 경험값이다. CFA 시험에서는 절대 기준으로 쓰면 안 된다 — 산업·사업모델·시계열 추세·동종업계 비교로 판단해야 한다. 예: 유통업과 소프트웨어의 Current Ratio는 직접 비교 불가, 높은 Current Ratio는 운전자본 비효율일 수도 있다.
비율공식의미실무 참고치
(CFA 절대기준 아님)		보수성
Current Ratio
유동비율		 Current Assets / Current Liabilities 단기 부채 상환 능력 — 가장 기본 >1.0 일반적
>2.0 안정적		 낮음
Quick Ratio
당좌비율		 (Cash + ST Inv + AR) / Current Liab
= (CA − Inventory) / CL		 재고 제외 즉시 상환 능력 >1.0 권장 중간
Cash Ratio
현금비율		 (Cash + ST Investments) / Current Liab 즉시 현금화 가능 자산만 가장 엄격 높음
Defensive Interval (Cash + ST Inv + AR) / Daily Operating Exp
⚠ Daily Op Exp = (Total Op Exp − D&A) ÷ 365
감가상각은 현금 지출 아님 → 반드시 제외		 외부 자금 없이 버티는 일수 높을수록 좋음 중간
⚠ Current Ratio 높다고 무조건 좋은 것 아님 — 재고 과다, AR 회수 불능인 경우도 있음 → Quick Ratio 함께 확인

부채/레버리지 비율 전체
⚠ 아래 실무 참고치는 여신심사 경험값이다. CFA 시험에서는 절대 기준으로 쓰면 안 된다 — 산업·사업모델·시계열 추세·동종업계 비교로 판단해야 한다. 예: 유통업과 소프트웨어의 Current Ratio는 직접 비교 불가, 높은 Current Ratio는 운전자본 비효율일 수도 있다.
비율공식의미높으면실무 참고치
(CFA 절대기준 아님)
Debt-to-Equity (D/E) Total Debt / Total Equity
Total Debt = 이자성 부채만
(차입금+사채 / AP·미지급비용 제외)		 자기자본 대비 부채 수준 주의 레버리지↑ 업종별 상이
Debt-to-Assets Total Debt / Total Assets
Total Liabilities ≠ Total Debt
이자성 부채만 분자에 포함		 자산 중 부채 비중 주의 부채의존도↑ <0.5 일반적
Financial Leverage Avg Total Assets / Avg Total Equity DuPont Leverage factor 주의 재무위험↑ DuPont 3번째
Interest Coverage ★★
이자보상배율		 EBIT / Interest Expense 이자 상환 능력 — 여신심사 핵심 좋음 상환 여력 <1.5x → 위험신호
Fixed Charge Coverage (EBIT + Lease) / (Interest + Lease) 고정비용 전체 커버 능력 좋음 높을수록 안전
DSCR ★★
부채상환비율		 EBITDA / (Interest + Principal Repayment) 원리금 상환 능력 — 여신심사 핵심 좋음 상환 여력 >1.25x 일반적 기준
여신심사 핵심 — Interest Coverage vs DSCR
Interest Coverage = EBIT / Interest
  • 이자만 커버하는지 확인
  • 감가상각 차감 후 (EBIT 기준)
  • 1.0x = 번 돈 전부 이자로 냄
  • 1.0 이하 = 이자도 못 냄
1.5x 미만 → 위험신호 / 1.0x 미만 → 즉각 경보
DSCR = EBITDA / (이자 + 원금상환)
  • 원리금(이자+원금) 전체 커버
  • 감가 더함 (현금 기준에 가까움)
  • 실제 대출 심사에서 더 중요
  • 1.0x = 원리금 겨우 커버
1.25x 이상이 일반적 여신 기준

ROE 분석 — 진짜 개선 vs 가짜 개선
진짜 좋은 ROE 개선
  • NPM ↑ → 수익성이 실제로 좋아진 것
  • Asset Turnover ↑ → 자산을 더 효율적으로 사용
  • EBIT Margin ↑ → 영업 자체가 강해진 것
가짜 ROE 개선 (위험)
  • Financial Leverage ↑ → 부채 늘려서 분모(Equity) 줄인 것
  • ROE ↑인데 ROA는 그대로 → Leverage 때문
  • Interest Coverage ↓ 동반 → 재무위험 증가

자주 나오는 함정
공식 함정
  • Inventory Turnover 분자 → COGS (Revenue 아님)
  • AR Turnover 분자 → Credit Sales 원칙 (현금매출 제외)
  • AP Turnover 분자 → COGS (Revenue 아님)
  • ROA 분자 → NI or EBIT(1−t) (문제에서 확인)
  • DuPont Leverage → Assets/Equity (Debt/Equity 아님)
  • Defensive Interval 분모 → Total Op Exp − D&A (비현금 제외)
  • D/E, Debt-to-Assets 분자 → 이자성 부채만 (AP·미지급비용 제외)
해석 함정
  • Current Ratio 높음 → 무조건 좋은 것 아님 (재고 과다일 수 있음)
  • ROE 높음 → Leverage 때문일 수 있음 (DuPont 확인)
  • DPO 높음 → 지급 느린 것 → 유리 (나쁜 것 아님)
  • Interest Coverage 1.0x → 이자 겨우 커버 → 위험
  • CCC 높음 → 현금 묶임 → 나쁨

비율별 방향 요약
높을수록 좋음
  • Profit Margins (GPM, OPM, NPM)
  • ROA / ROE / ROCE
  • Asset Turnover (효율)
  • Interest Coverage / DSCR
  • Current Ratio / Quick Ratio
  • Inventory Turnover / AR Turnover
낮을수록 좋음

  • Days Sales Outstanding (빨리 회수)
